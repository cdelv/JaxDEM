Intro to JaxDEM reinforcement learning#

This tutorial runs a tiny Proximal Policy Optimization (PPO) training loop for a sphere navigating toward a target in a reflective box, using SingleNavigator. A SharedActorCritic MLP maps observations to a continuous force policy and a value estimate. Install JaxDEM[rl,io] for the experimental RL tools and optional VTK export used here.

Four environments, short rollouts and two update epochs keep the walkthrough quick. This budget checks the training and evaluation pipeline; it does not produce a reliably trained navigator. First-call JAX compilation can dominate runtime. Increase the budget and evaluate many independent episodes before making a claim about learning quality.

Environment and action intervals#

import jax
import jax.numpy as jnp

import tempfile
from pathlib import Path

import numpy as np
import optax
from flax import nnx

import jaxdem as jdem
import jaxdem.rl as rl
from jaxdem import utils

num_steps_epoch = 16
skip_frames = 4
num_envs = 4
num_epochs = 2
# Each decision requests five physics steps. The evaluation below requests
# 1800 decisions (9000 physics frames), long enough to make the motion visible.
# Saving endpoints does not change the policy action interval.
decisions_per_frame = 40
frames_per_target = 15
evaluation_steps = 3 * frames_per_target * decisions_per_frame
env = rl.Environment.create(
    "single_navigator",
    min_box_size=8.0,
    max_box_size=8.0,
    max_steps=(evaluation_steps + 1) * (1 + skip_frames),
)

A scalar environment has fixed agent slots. Observations have shape (max_num_agents, observation_space_size); continuous actions have shape (max_num_agents, action_space_size). Vectorization prepends an environment axis. Inactive slots are masked out of the learning objective.

skip_frames=k repeats an action for at most 1+k physics frames, stopping at an episode boundary. PPO distinguishes termination from external truncation: only the latter bootstraps the value at the boundary. Evaluation helpers freeze completed episodes until the caller explicitly resets them.

Reward and the actor–critic decomposition#

reward() rewards progress through a distance potential:

\[\Phi(d)=e^{-2d},\qquad r_t=\Phi(d_{\rm end})-\Phi(d_{\rm start}).\]

The start is checkpointed once before repeating an action; the end is the live state after all accepted physics frames. Positive reward therefore means that the agent ended closer to the target. It does not require the distance to decrease on every intermediate frame. Observations and rewards read the live endpoint without advancing that checkpoint.

The shared MLP has policy and value heads. The policy produces a distribution \(\pi_\theta(a\mid o)\) for exploration; the value head estimates expected discounted return. An advantage compares a sampled return with this baseline, guiding the policy toward actions with better-than-expected outcomes.

Model and constrained actions#

MaxNormSpace constrains sampled force magnitudes to one while retaining a differentiable probability density. Constructor registry keys ignore case and underscores. The small architecture is sufficient for an API walkthrough. The action space is a bijector, so transformed action probabilities include its Jacobian correction. It preserves direction and maps a standard isotropic Gaussian to a uniform ball; learned means and variances still shape the resulting policy. This lets PPO use a bounded action distribution without applying an additional hard clipping operation that changes sampled actions. See MaxNormSpace for the radial transform and its analytic entropy expression.

model = rl.Model.create(
    "SharedActorCritic",
    key=nnx.Rngs(jax.random.key(1)),
    architecture=[16, 16],
    observation_space_size=env.observation_space_size,
    action_space_size=env.action_space_size,
    action_space=rl.ActionSpace.create("max_norm", max_norm=1.0),
)

Configure PPO#

One epoch collects 4*16=64 single-agent transitions. Two minibatches each contain two complete 16-step environment segments. num_epochs counts rollout/update iterations, not replay passes. optax.adam keeps this introductory example small; optimizer choice and larger budgets require separate tuning. PPO compares the live policy with the behavior policy that collected the rollout. For stored actions, its clipped surrogate is

\[\begin{split}\begin{aligned} \rho_t(\theta) &= \frac{\pi_\theta(a_t\mid o_t)}{\pi_{\rm old}(a_t\mid o_t)}, \\ L_{\rm policy} &= -\mathbb E_t\left[ \min\left(\rho_t A_t, \operatorname{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t\right)\right]. \end{aligned}\end{split}\]

The ratio clipping limits the objective’s incentive for large policy changes; it is unrelated to constraining the physical force magnitude. The trainer also fits the value head and includes entropy regularization. Active-agent masks determine which transitions contribute to these averages.

The default vtrace=False uses generalized advantage estimation with live minibatch value predictions and fixed collection-time bootstraps at rollout and truncation boundaries. Advantages are used without normalization, while behavior log-probabilities and the value-clipping reference stay fixed. A minibatch contains complete fixed-horizon segments; those segments may cross episode boundaries and need not be complete episodes.

Increase num_envs for more independent data, num_steps_epoch for longer segments, and num_epochs for more collect/update iterations. These affect data and optimization differently. A longer run can use train() and its logging/directory options, or retain the explicit epoch() loop shown here to inspect diagnostics and implement a stopping criterion.

tr = rl.Trainer.create(
    "PPO",
    env=env,
    model=model,
    key=jax.random.key(6),
    optimizer=optax.adam,
    num_steps_epoch=num_steps_epoch,
    num_envs=num_envs,
    num_epochs=num_epochs,
    skip_frames=skip_frames,
    num_minibatches=2,
    learning_rate=1e-3,
)

Run and inspect two update epochs#

train() is the convenience loop (train(tr, verbose=False, log=False)). Calling epoch() directly exposes the scalar diagnostics for this short tutorial. Finite losses establish a working update, not successful target reaching.

for epoch in range(num_epochs):
    tr, _transitions, metrics = tr.epoch(tr, jnp.asarray(epoch, dtype=int))
    loss = float(metrics["loss"])
    assert np.isfinite(loss)
    print(f"Epoch {epoch}: loss={loss:.4g}, mean score={float(metrics['score']):.4g}")
tr.env.system.check_overflow()

Evaluate the live model#

The trainer has its own vectorized environments. Reset the serial environment separately with reset() and a reproducible key. Recurrent models need their memory reset too; the feedforward model used here ignores this operation.

tr.key, subkey = jax.random.split(tr.key)
env = env.reset(env, subkey)
base_model = tr.model
base_model.eval()
base_model.reset(shape=(env.max_num_agents, 1), mask=None)
graphdef, graphstate = nnx.split(base_model)

flax.nnx.split separates static graph structure (graphdef) from mutable graph state (graphstate). The callback uses flax.nnx.merge to combine them, samples an action with the supplied key, then returns the new state. Threading that state through the evaluator also supports recurrent models. Such models need memory resets at episode/agent boundaries; reset() is harmless for this feedforward MLP. Setting evaluation mode changes model behavior such as dropout; sampling the returned action distribution remains stochastic in this callback.

@jax.jit
def policy_model(obs, key, graphstate, graphdef):
    model = nnx.merge(graphdef, graphstate)
    distribution, _value = model(obs, sequence=False)
    action = distribution.sample(seed=key)
    _, graphstate = nnx.split(model)
    return action, graphstate

Save an initial frame and fifteen endpoints for each of three target phases. A small marker sphere identifies the target. The longer evaluation lasts 18 physical time units without increasing the two-update training budget. Distance summaries remain descriptive; this policy need not reach a target. A context manager completes asynchronous output before exit. Each env_step() call with n=40, skip_frames=4 makes 40 policy decisions and 200 physics steps. Three phases of fifteen calls make all 1800 decisions. The horizon above exceeds the resulting 9000 physics steps; otherwise evaluation would freeze at the episode boundary. These 46 saved frames retain their native times. The target marker is appended with add() only to the state sent to VTKWriter. It does not become an interacting particle in the environment or affect the policy. The embedded movie marks the same recorded objectives with orange rings.

frames_dir = Path(tempfile.mkdtemp(prefix="jaxdem-rl-tutorial-"))
scene_states = [env.state]
scene_systems = [env.system]
scene_targets = [np.asarray(env.env_params["objective"]).copy()]
with jdem.VTKWriter(directory=frames_dir) as writer:
    marker_state = env.state.add(
        env.state, pos=env.env_params["objective"], rad=env.state.rad / 5
    )
    writer.save(marker_state, env.system)
    for target_index in range(3):
        initial_distance = float(
            jnp.linalg.norm(env.state.pos_c - env.env_params["objective"])
        )
        for _ in range(frames_per_target):
            env, tr.key, graphstate = utils.env_step(
                env,
                policy_model,
                tr.key,
                graphstate,
                graphdef=graphdef,
                n=decisions_per_frame,
                skip_frames=skip_frames,
            )
            scene_states.append(env.state)
            scene_systems.append(env.system)
            scene_targets.append(np.asarray(env.env_params["objective"]).copy())
            marker_state = env.state.add(
                env.state, pos=env.env_params["objective"], rad=env.state.rad / 5
            )
            writer.save(marker_state, env.system)
        final_distance = float(
            jnp.linalg.norm(env.state.pos_c - env.env_params["objective"])
        )
        print(
            f"Target {target_index}: distance "
            f"{initial_distance:.3f} -> {final_distance:.3f}"
        )
        if target_index < 2:
            tr.key, subkey = jax.random.split(tr.key)
            low = env.state.rad[0]
            env.env_params["objective"] = jax.random.uniform(
                subkey,
                env.env_params["objective"].shape,
                minval=low,
                maxval=env.system.domain.box_size - low,
            )

evaluation_positions = np.asarray([state.pos_c[0] for state in scene_states])
evaluation_displacements = np.linalg.norm(
    evaluation_positions - evaluation_positions[0], axis=-1
)
assert np.isfinite(evaluation_positions).all()
assert float(evaluation_displacements.max()) > 0.5
assert int(env.system.step_count) == evaluation_steps * (1 + skip_frames)
env.system.check_overflow()
print(f"Largest evaluation displacement: {evaluation_displacements.max():.3f}")
print(f"Evaluation advanced {int(env.system.step_count)} physics frames.")
print(f"Open the PVD collection in ParaView: {frames_dir}")

Orange rings mark the environment’s actual targets. They are display annotations projected in front of the agent spheres, with radius 0.35; they are not extra simulated particles.
