Colliders#

A Collider detects interacting particle pairs and evaluates the ForceModel on each pair. Pass collider_type=None to disable non-bonded contacts altogether (e.g. for bonded-only or external-force-only systems).

import jaxdem as jdem
from jaxdem.utils.neighbor_list_sizing import (

Naive Collider#

NaiveSimulator (default) checks every pair \((i, j)\) with zero spatial-search setup or overflow risk. It is fast for small \(N\) and stores pair history densely as history[i, j]:

system_naive = jdem.System.create(state.shape, collider_type="naive")
state, system_naive = jdem.System.initialize(state, system_naive)
state_out, system_out = jdem.System.step(state, system_naive)
print("Naive forces:\n", state_out.force)

Naive forces:
 [[-4375.     0.]
 [    0.     0.]
 [ 4375.     0.]]

Cell List and Multi-Cell List#

Pass state= to create() so spatial colliders automatically infer defaults like cell_size from particle radii.

  • DynamicCellList ("cell_list") bins particles into a uniform implicit grid and probes neighboring cells.

  • DynamicMultiCellList ("multi_cell_list") attaches an expandable bounding box to each cell so a few large particles do not force a huge cell size on small ones.

state_p = jdem.State.create(
    pos=jnp.array([[1.0, 1.0], [2.5, 1.0], [5.0, 5.0]]),
    rad=jnp.full(3, 0.5),
)
system_cl = jdem.System.create(state=state_p, collider_type="cell_list")
system_mcl = jdem.System.create(state=state_p, collider_type="multi_cell_list")
print("CellList cell_size:", system_cl.collider.cell_size)
print("MultiCellList cell_size:", system_mcl.collider.cell_size)

CellList cell_size: 1.0
MultiCellList cell_size: 1.0

Fixed-Capacity (Static) Cell Traversal#

By default static=False uses dynamic while_loop traversal (no tile capacity limit, forward-mode AD only). Set static=True (or pass an explicit tile_capacity budget) for fixed-tile traversal that supports reverse-mode AD and avoids dynamic loops; always check check_overflow() afterward:

for collider_type in ("cell_list", "multi_cell_list"):
    system_static = jdem.System.create(
        state=state_p,
        collider_type=collider_type,
        collider_kw={"static": True},
    )
    _, system_static = jdem.System.initialize(state_p, system_static)
    system_static.check_overflow()
    print(collider_type, "tile_capacity:", system_static.collider.tile_capacity)

cell_list tile_capacity: 9
multi_cell_list tile_capacity: 9

Explicit Neighbor Queries#

Every collider exposes create_neighbor_list(), returning (state, system, neighbor_list, overflow) where neighbor_list has shape (N, max_neighbors) padded with -1. Always check overflow (if True, increase max_neighbors). Use create_cross_neighbor_list() when querying neighbors between two distinct particle sets:

state_p, system_cl, nl_cl, overflow_cl = system_cl.collider.create_neighbor_list(
    state_p, system_cl, cutoff=2.0, max_neighbors=8
)
print("Neighbor list (cutoff=2.0):\n", nl_cl)
print("Overflow:", bool(overflow_cl))

Neighbor list (cutoff=2.0):

 [-1 -1 -1 -1 -1 -1 -1 -1]]
Overflow: False

Neighbor List Collider#

NeighborList caches candidate pairs built by a secondary_collider_type (default "cell_list"; never another "neighbor_list") and rebuilds only when any particle moves more than skin / 2 or domain geometry changes.

Key parameters:

  • cutoff — search reach (automatically expanded if the force law needs more).

  • skin or skin_fraction (default 0.05) — buffer distance before triggering a rebuild (pass at most one).

  • max_neighbors — average slot budget per particle (all N * max_neighbors slots are shared in one pool, so individual particles may exceed the average).

Warning

Under jax.vmap, per-replica rebuild branches can execute across the batch unless caches stay synchronized; benchmark rebuild frequency for your batch size.

system_nl = jdem.System.create(
    state=state_p,
    collider_type="neighbor_list",
    collider_kw={
        "cutoff": 2.0,
        "skin": 0.1,
        "secondary_collider_type": "cell_list",
        "max_neighbors": 8,
    },
)
_, system_nl = jdem.System.initialize(state_p, system_nl)
system_nl.check_overflow()
print(
    f"NeighborList: cutoff={float(system_nl.collider.cutoff)}, "
    f"skin={float(system_nl.collider.skin)}, "
    f"max_neighbors={system_nl.collider.max_neighbors}, "
    f"builds={int(system_nl.collider.n_build_times)}"
)

NeighborList: cutoff=2.0, skin=0.1, max_neighbors=8, builds=1

Automatic Neighbor-List Capacity Sizing#

Rather than guessing max_neighbors by trial and error—especially for dense, polydisperse, or multi-sphere clump packings—use the host-side sizing helpers in jaxdem.utils.neighbor_list_sizing before launching a compiled run:

  • measure_neighbor_candidates() counts exact candidate degrees on the current snapshot without allocating a neighbor buffer.

  • estimate_neighbor_capacity() scales and relaxes periodic bounding spheres to a target packing_fraction (sampling clump orientations when needed) and returns rounded capacities for both pooled NeighborList (max_neighbors) and dense create_neighbor_list() queries (query_max_neighbors).

state_dense = jdem.utils.grid_state(n_per_axis=(4, 4), spacing=2.0)
state_dense.rad = jnp.where(jnp.arange(state_dense.N) % 2 == 0, 0.4, 0.6)
sys_probe = jdem.System.create(
    state=state_dense,
    domain_type="periodic",
    domain_kw={"box_size": jnp.array([8.0, 8.0])},
)

stats = measure_neighbor_candidates(state_dense, sys_probe, skin_fraction=0.1)
print(
    f"Current snapshot: mean_deg={stats.mean_degree:.2f}, "
    f"max_deg={stats.max_degree}, list_cutoff={stats.list_cutoff:.2f}"
)

est = estimate_neighbor_capacity(
    state_dense,
    sys_probe,
    packing_fraction=0.75,
    skin_fraction=0.1,
    safety_factor=1.25,
    extra_neighbors=2,
)
print(
    f"Recommended at phi=0.75: max_neighbors={est.max_neighbors} (pooled), "
    f"query_max_neighbors={est.query_max_neighbors} (dense)"
)

sys_sized = jdem.System.create(
    state=state_dense,
    domain_type="periodic",
    domain_kw={"box_size": jnp.array([8.0, 8.0])},
    collider_type="neighbor_list",
    collider_kw={
        "cutoff": est.cutoff,
        "skin": est.skin,
        "max_neighbors": est.max_neighbors,
    },
)
_, sys_sized = jdem.System.initialize(state_dense, sys_sized)
sys_sized.check_overflow()

Current snapshot: mean_deg=4.00, max_deg=4, list_cutoff=2.20
Recommended at phi=0.75: max_neighbors=16 (pooled), query_max_neighbors=16 (dense)

Overflow Checks and Editing State#

Neighbor lists and static cell lists use fixed-size buffers. Call check_overflow() after initialization and simulation chunks to raise an error if any buffer overflowed.

If you edit positions, radii, or particle counts manually on host:

  • Use jaxdem.colliders.invalidate_collider() when N and buffer capacities are unchanged (forces a cache rebuild on the next query).

  • Use jaxdem.colliders.refresh_collider() when N or capacities changed (pass reset_history=True only if pair identities changed).

system_nl.collider = jdem.colliders.refresh_collider(edited_state, system_nl.collider)

Computing Pairwise Potential Energy#

compute_potential_energy() returns (state, system, potential_energy) so any cache rebuilds are preserved:

state_pe = jdem.State.create(
    pos=jnp.array([[0.0, 0.0], [1.5, 0.0]]), rad=jnp.ones(2)
)
system_pe = jdem.System.create(state_pe.shape, force_model_type="spring")
state_pe, system_pe, pe = system_pe.collider.compute_potential_energy(
    state_pe, system_pe
)
print("Total pairwise potential energy:", float(pe))

Total pairwise potential energy: 1250.0
