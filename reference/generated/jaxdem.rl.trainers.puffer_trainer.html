jaxdem.rl.trainers.puffer_trainer#

Pure-Python wrapper to train JaxDEM RL environments with PufferLib (4.0+).

Bridges PufferEnvWrapper (JIT-compiled JAX environments) directly to PufferLib 4.x’s PyTorch models (pufferlib.models.Policy, DefaultEncoder, DefaultDecoder, MinGRU/MLP) and optimizer (pufferlib.muon.Muon or Adam).

pufferlib is an optional dependency required only when using this module or jaxdem.rl.trainers.protein_sweep.
