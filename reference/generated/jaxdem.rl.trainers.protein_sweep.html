jaxdem.rl.trainers.protein_sweep#

PufferLib Protein Pareto-frontier hyperparameter optimizer for JaxDEM RL.

Pure-Python wrapper around pufferlib.sweep.Protein (dual Gaussian Processes for score and log-cost, Pareto-frontier centered search, pinball-loss quantile early stopping, and logistic failure classification) that sweeps hyperparameters on any JaxDEM Environment using PufferTrainer, JaxDEM’s PPOTrainer, or a custom evaluation callback.

Build a JIT-compiled deterministic full-episode evaluator for PPOTrainer.

Parameters:

  • env (Environment) – Single (unvectorized) JaxDEM environment.

  • metric_fn (callable, optional) – Pure-JAX function (final_env, rewards) -> scalar evaluated inside jax.jit after one deterministic episode of ep_decisions steps on eval_n fixed held-out reset states. final_env is the live vectorized end-of-episode environment (before reset) and rewards has shape (ep_decisions, eval_n, max_num_agents). When omitted, defaults to the mean cumulative episode return jnp.mean(jnp.sum(rewards, axis=0)).

  • eval_n (int) – Number of fixed held-out environments to average over.

  • skip_frames (int) – Action repeat count matching training.

  • max_steps (int, optional) – Episode length in physics steps. Inferred from env.env_params["max_steps"] when omitted.

  • seed (int) – Fixed seed for held-out initial states.

Pareto-frontier hyperparameter sweeper for JaxDEM RL environments.

Accepts any JaxDEM Environment (or factory accepting swept env.* parameters) and runs pufferlib.sweep.Protein to discover the score-vs-wall-clock-cost Pareto frontier.

Supports three execution backends:

  • backend="puffer" (default): PufferTrainer (pufferlib.pufferl.PuffeRL).

  • backend="ppo": JaxDEM’s full-JIT PPOTrainer.

  • evaluate_fn: custom callable (params, should_stop) -> dict for arbitrary training loops.
